# 🍽️ Recipe Management System

A simple and interactive web-based application to manage your favorite recipes. Built using **HTML**, **CSS**, and **JavaScript**, this project allows users to save, edit, and delete recipes with ease — all within the browser.

## 🚀 Features

- ✅ Add and store recipes temporarily
- 📝 Edit existing recipe details
- ❌ Delete recipes with a single click
- 🎨 Clean and responsive UI with background image
- 💾 No backend — all data is stored in the DOM
